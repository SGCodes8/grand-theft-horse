# Grand Theft Horse VI

A browser chase game set in Vice City. You're the horse. Jump the traffic, eat the carrots and Sami's Bagel Bread, and don't get busted.

**Play:** https://sgcodes8.github.io/grand-theft-horse/#play

Controls: Space, ↑ or tap to jump. Press again in the air to double jump. M toggles the music.
